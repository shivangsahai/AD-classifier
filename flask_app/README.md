# EEG Based Alzheimer's Detection - Flask App

This folder contains the HTML, CSS, JavaScript, and Flask version of the EEG Alzheimer's detection interface.

## Run

```powershell
cd "C:\Users\Asus\Desktop\Data Science\4_ml\projects\4. ad_classifier\flask_app"
python -m pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000`.

The app loads `../artifacts/model.joblib` and `../artifacts/scaler.joblib`.
